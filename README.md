A tiny paper-trading bot for hourly Solana bars. It rides a trend only once two hourly bars in a row agree it is up (EMA 8 over EMA 21, close above the slow average), sits in USDC the rest of the time, and caps every loss with a hard stop plus a trailing stop. One program, no outside data, no network — it speaks the agent-fun/bars-replay/v1 protocol on stdin/stdout.

## Run it

```sh
node main.ts
```
